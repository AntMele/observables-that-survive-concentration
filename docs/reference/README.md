# Paper reference

[Home](../../README.md) / [Reader guide](../README.md) / Reference

The [paper-to-code map](paper-map.md) connects manuscript labels and proof
ingredients to the corresponding Lean declarations and source files.
It distinguishes completed results from statements outside the formalization.

## Find a result

- Start with the [complete paper-to-code map](paper-map.md) when following a theorem or lemma in the paper.
- Read a [result guide](../results/README.md) for the English statement and its assumptions.
- Use the [Lean source index](../../Fluctuations/README.md) to browse supporting modules by topic.

The [manuscript provenance](paper-map.md#manuscript-provenance) identifies the
inspected draft. When referring to a formal result, record the paper version,
repository revision, and Lean declaration together.
